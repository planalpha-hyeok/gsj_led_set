# GSJ LED 플레이어

LED 전광판 여러 대를 하나의 캔버스(전체 해상도)로 묶어 재생하는 Windows용 프로그램입니다.

현재 버전: **0.5.0 (큐 타임라인, 소리 재생)** — 창 제목에 버전이 표시됩니다.

## 기능

| 기능 | 내용 |
|---|---|
| 캔버스 | 전체 해상도 자유 지정 (최대 65536 × 65536) |
| 영역 | 캔버스 위 X, Y, 너비, 높이를 픽셀 단위로 지정. 송출카드 매핑 좌표와 같은 값 사용 |
| 출력 | 그래픽카드 출력마다 출력 창 1개. 여러 그래픽카드 지원 |
| 장면 | 영역별 콘텐츠 묶음. 영역 위치는 모든 장면 공통, 콘텐츠만 장면마다 다름 |
| 플레이리스트 | 영역마다 영상/이미지 여러 개를 순서대로 재생. 항목별 재생 시간, 컷/페이드 전환, 목록 반복 |
| 흐르는 자막 | 여러 문구 순환, 글꼴/크기/색/배경, 외곽선, 그림자, 속도, 방향(←→↑↓), 텍스트 파일 실시간 반영 |
| 스케줄 | 요일/특정 날짜 + 시각별 장면 자동 전환, 자정 넘김, 일정 없는 시간 정지 또는 기본 장면 |
| 자동 실행 | 프로그램 시작 시 마지막 프로젝트를 열고 출력 켜기 + 재생(또는 스케줄 운영) |
| 맞춤 방식 | 늘리기 / 맞추기 / 채우기 / 원본 1:1 |
| 하드웨어 디코딩 | 그래픽카드(D3D11VA)로 영상 처리. 전체 켜기/끄기(캔버스 탭) + 영역별 설정(영역 탭). 지원하지 않으면 자동으로 CPU |
| 큐 타임라인 | 시간축에 영상/이미지/소리 클립 배치, 여러 레이어, 클립 여러 개 선택, 자르기, 페이드, 불투명도, 소리 크기, 큐 지점(GO), 일시정지/이동, 끝 동작 |
| 소리 | 타임라인의 소리 파일과 영상 속 소리 재생 (Windows 기본 소리 장치) |
| 라이브 입력 | 캡처보드/웹캠을 플레이리스트 항목으로 표시 (최신 프레임, 끊기면 2초마다 재연결) |
| 인터랙티브 | UDP/TCP/OSC/시리얼/MIDI/출력 화면 터치로 장면 전환, 재생/정지, 다음/이전, 자막 변경, 영역 표시/숨김 |
| 동기화 | 디코딩이 늦으면 프레임을 건너뛰어 재생 시각을 따라잡음. 6ms 이내로 화면을 갱신하는 출력들은 같은 프레임 표시 |
| 테스트 패턴 | 출력마다 격자(64px, 256px), 테두리, 대각선, 영역 위치와 좌표 표시 |
| 프로젝트 | `.ledproj` 파일로 저장/불러오기 (1단계 파일은 자동 변환) |
| 기록 | 화면 아래 기록 창 + 로그 파일 |

## 실행 파일 받기

1. GitHub 저장소의 **Actions** 탭 → **build-windows** → 최신 실행 항목 선택
2. 아래쪽 **Artifacts**의 `gsj_led_player-windows` 다운로드 후 압축 해제
3. `gsj_led_player.exe` 실행

필요 환경: Windows 10 / 11 (64비트), DirectX 11을 지원하는 그래픽카드

## 사용 방법

### 1) 출력 설정 (출력 탭)
- **출력 1개 = 그래픽카드 출력(HDMI/DP) 1개**입니다.
- `디스플레이`: 송출카드가 연결된 출력을 선택합니다 (예: `\\.\DISPLAY2`). 목록에 그래픽카드 이름, 해상도, 바탕화면 위치가 표시됩니다.
- `캔버스 범위`: 이 출력이 내보낼 캔버스 부분입니다. 출력 창은 이 범위를 **1:1 픽셀**로 그대로 내보냅니다.
- `크기를 디스플레이 해상도로 설정`: 너비/높이를 해당 디스플레이 해상도로 맞춥니다.
- `디스플레이 내 위치`: 출력 창을 디스플레이 좌상단에서 띄울 거리입니다. 보통 0, 0입니다.

### 2) 캔버스 설정 (캔버스 탭)
- `출력 범위 전체에 맞춤`을 누르면 모든 출력이 들어가는 크기로 설정됩니다.

### 3) 영역 설정 (영역 탭)
- 목록에서 영역 선택 → `위치/크기`의 X, Y, 너비, 높이에 숫자 입력 후 **Enter** (또는 다른 칸 클릭) 하면 반영됩니다.
  좌표는 NovaLCT / LEDVISION 매핑 좌표와 같은 기준입니다. 새 영역은 `추가`.
- 가운데 캔버스 화면에서 마우스로 편집할 수 있습니다 (정수 픽셀 단위).
  - **이동**: 영역 안쪽을 끌기 / **크기**: 테두리나 모서리(흰 조절점)를 끌기
  - **자석**(도구모음): 캔버스·출력·다른 영역의 테두리와 가운데선 근처(화면 8px 이내)에서 붙음. 옮길 때는 영역의 가운데도 붙음. 붙으면 분홍 점선 표시. 드래그 중 **Alt**를 누르면 일시 해제
  - **방향키**: 1px 이동 (Shift: 10px), **Ctrl+방향키**: 너비/높이 변경
  - 마우스로 바꾼 값은 오른쪽 숫자 칸에 바로 반영되고, 숫자로 입력해도 됩니다.
- 목록 위쪽에 있는 영역이 화면 앞쪽에 그려집니다 (`앞으로` / `뒤로`).
- 아래 **콘텐츠** 칸에서 **편집 중인 장면**의 내용을 정합니다.
  - **플레이리스트**: `파일 추가...`로 여러 파일 선택.
    - 재생 시간 `자동`: 영상은 끝까지 1회, 이미지는 10초. 숫자를 넣으면 그 시간만큼 재생 (영상이 짧으면 반복).
    - 시작 전환: `컷`(즉시) 또는 `페이드`(지정 시간 동안 겹치며 바뀜).
    - 항목이 1개이고 `목록 반복`이 켜져 있으면 그 영상이 끊김 없이 계속 반복됩니다.
  - **흐르는 자막**: 한 줄에 문구 하나씩 입력. 문구들이 차례로 이어서 흐릅니다.
    - `자막 파일`을 지정하면 .txt 파일 내용을 사용하고, 재생 중 파일을 저장하면 1초 안에 새 내용으로 처음부터 다시 흐릅니다.
    - 배경색을 투명으로 두면 아래 영역(영상)이 보이므로, 자막 영역을 영상 영역 **앞쪽**에 두세요.

### 4) 장면 (장면 탭)
- 장면 = 영역별 콘텐츠 묶음입니다. 선택한 장면이 '영역' 탭의 편집 대상이 됩니다.
- `복제`로 비슷한 장면을 빠르게 만들 수 있습니다. `▶ 이 장면 재생`으로 바로 확인합니다.

### 5) 스케줄 (스케줄 탭)
- `추가` → 이름, 장면, 적용(요일 반복 / 특정 날짜), 시각 입력.
- 우선순위: **특정 날짜 일정 > 요일 일정**, 같은 종류는 **목록 위쪽 우선**.
- 종료가 시작보다 이르면 다음날까지 (예: 22:00~02:00), 시작과 종료가 같으면 하루 종일.
- `일정 없는 시간`: 정지(검은 화면) 또는 기본 장면 재생.
- 도구모음 **스케줄 운영**(F8)을 누르면 시각에 맞춰 장면이 자동으로 바뀝니다. 스케줄 운영 중 오류는 대화상자 없이 기록 창/로그 파일에만 남습니다.
- `프로그램 시작 시 자동 실행`을 켜고 저장하면, 다음 실행 때 마지막 프로젝트를 열고 바로 출력/재생을 시작합니다 (Windows 시작프로그램에 등록해 무인 운영 가능).

### 6) 라이브 입력 (영역 탭 → 플레이리스트)
- `라이브 입력 추가...` → 입력 장치(캡처보드/웹캠) 선택, 해상도/프레임은 모르면 '자동'.
- 재생 시간 '자동'이면 계속 표시합니다. 시간을 넣으면 그 시간 뒤 다음 항목으로 넘어갑니다.
- 장치가 끊기면 마지막 화면을 유지하고 2초마다 다시 연결합니다.

### 7) 인터랙티브 (인터랙티브 탭)
- 외부 입력을 켭니다: UDP / TCP / OSC (포트), 시리얼 (COM 포트, 속도), MIDI (장치), 출력 화면 터치/클릭.
- 명령 (한 줄에 하나, 이름에 공백이 있으면 "따옴표"):

| 명령 | 한글 | 동작 |
|---|---|---|
| `scene <장면 이름 또는 번호>` | 장면 | 장면 전환 (스케줄 운영 중이면 스케줄 운영을 끔) |
| `play` / `stop` | 재생 / 정지 | 재생 / 정지 |
| `next <영역>` / `prev <영역>` | 다음 / 이전 | 플레이리스트 다음/이전 항목 |
| `text <영역> <문구>` | 자막 | 자막 문구 변경 (`\|`로 여러 문구) |
| `show <영역>` / `hide <영역>` | 표시 / 숨김 | 영역 표시/숨김 |
| `trigger <이름>` | 트리거 | 트리거 연결표의 명령 실행 |
| `reset` | 초기화 | 외부 명령으로 바꾼 자막/표시 되돌림 |

- TCP는 명령마다 `OK` 또는 `ERR <사유>`로 응답합니다.
- OSC는 주소와 인수를 그대로 명령으로 바꿉니다: `/scene "오전"`, `/next "메인"`, `/text "하단" "문구"`.
- **트리거 연결표**: 터치/MIDI 신호를 명령으로 연결합니다.
  - 터치: `touch:<영역 이름>` (출력 화면에서 그 영역을 누름. 콘텐츠 없는 영역도 버튼으로 사용 가능)
  - MIDI: `midi:note:<번호>`, `midi:cc:<번호>`, `midi:pc:<번호>`
  - 신호를 한 번 보내면 '마지막 트리거'에 이름이 표시되고 `마지막 트리거로 추가`로 바로 등록할 수 있습니다.
- `명령 시험` 칸에서 명령을 직접 실행해 볼 수 있습니다.
- 외부 명령으로 바꾼 자막/표시는 **프로젝트에 저장되지 않습니다** (프로그램을 다시 열거나 `reset`하면 원래대로).
- **보안**: 네트워크 입력을 켜면 같은 네트워크의 누구나 명령을 보낼 수 있습니다. 신뢰할 수 있는 네트워크에서만 켜세요. Windows 방화벽 허용 창이 뜨면 '개인 네트워크'만 허용하세요.

### 8) 큐 타임라인 (장면 탭 → `타임라인 추가`, 아래 '타임라인' 창)
- 타임라인은 장면의 한 종류입니다. 스케줄, 외부 명령(`scene`)으로 다른 장면처럼 재생할 수 있습니다.
- **레이어**: 위쪽 레이어가 화면 앞입니다. 레이어마다 표시 영역을 지정합니다 (영역 없음 = 소리만).
  레이어 머리의 `보임/숨김`, `소리/무음`, `편집/잠금` 버튼으로 바로 바꿀 수 있습니다.
- **클립 추가**: `파일 추가...`(선택한 레이어의 재생 위치), 오른쪽 클릭 메뉴, 또는 파일을 끌어다 놓기.
  여러 파일을 고르면 이어서 배치됩니다. 영상/소리는 파일 길이, 이미지는 5초.
- **편집**:
  - 끌어서 이동 (위아래로 끌면 다른 레이어), 양 끝을 끌어 자르기 (앞쪽을 자르면 파일 시작점도 같이 바뀜)
  - Ctrl+클릭, 빈 곳을 끌어 여러 개 선택 → 같이 이동, 속성 칸에서 바꾼 값은 선택한 모든 클립에 적용
  - 자석: 클립 끝, 큐, 재생 위치, 0초에 붙음 (Alt를 누르고 끌면 해제)
  - Delete 삭제, Space 재생/일시정지, Home 처음, Ctrl+휠 확대/축소, Shift+휠 가로 이동
- **클립 속성**: 시작, 길이, 자르기(파일 시작점), 페이드 인/아웃, 불투명도, 소리 크기, 반복(파일이 짧을 때)
- **큐 지점**: `큐 추가`(재생 위치). 재생 중 큐에 오면 멈추고 `GO`(또는 외부 명령 `go`)로 계속.
- **끝 동작**: 마지막 화면 유지 / 처음부터 반복 / 정지(검은 화면)
- **외부 명령**: `pause`, `go`, `seek 1:30`, `play`(멈춘 타임라인 이어서 재생)
- 같은 영역에서 클립을 겹치고 페이드를 주면 겹치는 구간이 서로 섞입니다 (위 레이어 / 나중 클립이 앞).

### 9) 확인과 재생
- `테스트 패턴`(F7): 출력마다 격자와 좌표, 영역 위치가 표시됩니다.
- `재생`(F5): 편집 중인 장면을 처음부터 재생합니다 (출력이 꺼져 있으면 자동으로 켬). 스케줄 운영 중이었다면 스케줄 운영은 꺼집니다.
- `정지`(Shift+F5): 출력 화면이 검은색이 되고 스케줄 운영도 꺼집니다.
- `출력 켜기`(F6): 출력 창 켜기/끄기

### 단축키

| 키 | 기능 |
|---|---|
| F5 / Shift+F5 | 재생 / 정지 |
| F8 | 스케줄 운영 켜기/끄기 |
| **Ctrl+Alt+F12** | **비상: 모든 출력·테스트 패턴 끄기 (어느 화면에서나)** |
| F6 | 출력 켜기/끄기 |
| F7 | 테스트 패턴 |
| F | 캔버스 화면 맞춤 |
| 마우스 휠 / 가운데 버튼 끌기 | 확대·축소 / 화면 이동 |
| Ctrl+N / Ctrl+O / Ctrl+S | 새 프로젝트 / 열기 / 저장 |

> **출력 화면이 편집 화면을 가려 조작할 수 없을 때: `Ctrl+Alt+F12`**
> 어느 화면에서나 모든 출력과 테스트 패턴을 끄고 편집 화면을 앞으로 가져옵니다.
>
> 주 모니터(편집 화면이 있는 화면)의 출력 창은 '항상 위'로 띄우지 않으므로 Alt+Tab, 작업 관리자도 사용할 수 있습니다.
> 다른 모니터(LED 송출용)의 출력 창은 다른 창에 가려지지 않도록 '항상 위'로 띄웁니다.

### Windows 화면 배율
출력 창은 물리 픽셀 기준으로 배치되므로 화면 배율(125%, 150% 등)과 관계없이 1:1로 출력됩니다.
단, 송출카드가 연결된 출력은 배율 100%를 권장합니다.

## 알려진 제한

- 하드웨어 디코딩은 그래픽카드에서 디코딩한 뒤 결과를 CPU 메모리로 복사합니다. 복사 비용이 있어 최고 성능은 아닙니다.
- 영상이 깨지거나 멈추면 하드웨어 디코딩을 끄고(캔버스 탭 또는 영역별) 확인하세요. 기록 창에 실제 사용한 디코딩 방식이 표시됩니다.
- 소리는 타임라인 장면에서만 재생합니다 (영역별 플레이리스트의 영상 소리는 재생하지 않음). Windows 기본 소리 장치로 출력합니다.
- 출력들의 화면 갱신 시점이 6ms 이상 차이 나면(다른 그래픽카드 등) 최대 1프레임 차이가 날 수 있습니다. 완전 동기화는 동기화 하드웨어(예: NVIDIA Quadro Sync)가 필요합니다.
- 콘텐츠 1개의 최대 해상도는 16384 × 16384입니다 (Direct3D 11 제한).
- 출력 설정을 바꾸면 출력 창이 잠시 다시 켜집니다.
- 자막 파일이 바뀌면 자막이 처음부터 다시 흐릅니다 (이어서 흐르지 않음).
- 영상 길이가 '자동'일 때 다음 항목 전환 시점은 파일 정보의 재생 길이를 기준으로 합니다.

## 로그 파일 위치

`%LOCALAPPDATA%\GSJ\GSJ LED Player\logs\player.log`

오류가 생기면 이 파일을 함께 전달해 주세요.

## 개발자용: 직접 빌드

필요한 것: Visual Studio 2022 (C++ 데스크톱 개발), CMake 3.21 이상, Qt 6.5 이상 (MSVC 64비트), FFmpeg 6.x ~ 8.x shared 빌드

```bat
set FFMPEG_ROOT=C:\ffmpeg\ffmpeg-n8.1-latest-win64-lgpl-shared-8.1
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH=C:\Qt\6.7.3\msvc2019_64
cmake --build build --config Release
ctest --test-dir build -C Release
```

### 소스 구조 (기능별 모듈)

| 폴더 | 역할 |
|---|---|
| `src/core` | 좌표 계산, 자석, 프로젝트 데이터, 스케줄 판정, 자막 위치 계산, 명령/OSC 해석, 로그 |
| `src/config` | 프로젝트 파일 저장/불러오기 |
| `src/media` | 영상(FFmpeg)/이미지/라이브 입력 디코딩, 자막 이미지 생성 |
| `src/playback` | 재생 엔진, 플레이리스트/자막/타임라인 재생 |
| `src/schedule` | 스케줄 실행기 (1초마다 장면 판단) |
| `src/interactive` | 외부 입력 수신 (UDP/TCP/OSC/시리얼/MIDI) |
| `src/render` | 장면 데이터, Direct3D 11 렌더러 |
| `src/display` | 디스플레이/그래픽카드 조회 |
| `src/output` | 출력 창 (출력마다 전용 렌더 스레드) |
| `src/testpattern` | 테스트 패턴 생성 |
| `src/ui` | 편집 화면 (`ui/timeline`: 타임라인 편집) |
| `third_party/miniaudio` | 소리 출력 라이브러리 (MIT-0) |
| `src/app` | 프로그램 시작, 로그 연결 |
| `tests` | 자동 테스트 |

## 라이선스 참고

FFmpeg는 LGPL 빌드를 사용하며 DLL로 동적 연결합니다. Qt는 LGPL로 동적 연결합니다. miniaudio는 퍼블릭 도메인/MIT-0입니다.
