# LED Wall Planner

LED 전광판 시공 전, **데이터 매핑**과 **전원 배선**을 미리 계산하고 배선도를 만드는 웹앱입니다.
NovaStar / Colorlight 장비를 지원합니다.

## 실행 방법

### 1) 파일로 실행 (인터넷 필요 없음)
```bash
npm install
npm run build
```
`dist/index.html` 파일 하나가 만들어집니다. 이 파일을 노트북·태블릿에 복사해서 브라우저(Chrome, Edge)로 열면 됩니다.

### 2) 개발 서버
```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 계산 모듈 테스트
```

## 기능

| 탭 | 내용 |
|---|---|
| 화면 배치 | 캐비닛 배치, 캐비닛 이름(A1, B2…), 시작 픽셀 좌표 |
| 데이터 배선 | 포트별 수동 배선, 포트 사용률, 컨트롤러·포트 번호 지정 |
| 전원 배선 | 회로별 수동 배선, 회로 전류, 3상 R/S/T 상 지정 |
| 요약 보고서 | 해상도·크기·무게·전력·자재 수량, 포트·회로 표 |

기본값: 캐비닛 640×480mm P1.86 (320×160 모듈 6개, 344×258px), 화면 5×3, Colorlight X4m

### 수동 배선 조작

| 동작 | 결과 |
|---|---|
| 캐비닛 클릭 / 드래그 | 선택한 포트(회로) 끝에 차례로 연결 |
| 드래그 중 바로 전 캐비닛으로 되돌아감 | 마지막 연결 취소 |
| 마지막 캐비닛 다시 클릭 | 마지막 연결 취소 |
| 중간 캐비닛 클릭 | 그 뒤를 잘라내고 거기서부터 다시 연결 |
| 다른 색 캐비닛 클릭 | 그 포트(회로)를 선택 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 (드래그 한 번 = 한 단계) |

### 배선도 화면 이동

| 동작 | 결과 |
|---|---|
| 휠 | 상하 이동 (더 이동할 곳이 없으면 페이지 스크롤) |
| Shift+휠 | 좌우 이동 |
| Ctrl+휠, 터치패드 확대 동작 | 확대·축소 |
| 빈 곳 드래그, 가운데 버튼 드래그 | 이동 |

검사 항목: 포트 용량 초과, 포트 번호 중복, 장비 포트 수 초과, 컨트롤러 총용량·최대 가로/세로, 회로 과부하, 중복 연결, 미연결 캐비닛, 붙어 있지 않은 캐비닛 연결, 3상 불평형

- 저장: 브라우저에 자동 저장, 프로젝트 목록, JSON 파일 저장/열기 (이전 버전 파일은 배선 없이 열림)
- 출력: 현재 탭 PNG, 전체 PDF 보고서 (A4 가로 5쪽)
- 목록에 없는 장비는 "장비 추가"로 사양서 값을 직접 입력

## 계산 기준

| 항목 | 기준 |
|---|---|
| 포트 용량 | 1G 포트 650,000px (8bit, 60Hz) |
| 10/12bit | 포트 용량 × 0.5 (보수적) |
| 주사율 | 포트 용량 × 60 ÷ 주사율 (근사치) |
| 캐비닛 전류 | 전력 ÷ (상전압 × 역률) |
| 회로 허용 전류 | min(차단기 × 사용률, 케이블 허용 전류) |
| 3상 분배 | 회로마다 상을 직접 지정 (새 회로는 전류가 가장 적은 상으로 시작), 불평형 15% 초과 시 경고 |
| 3상 선전류 | 전력 ÷ (√3 × 선간전압 × 역률) |

## 장비 사양 출처

각 장비에 출처 등급이 표시됩니다.

- **공식 사양**: 제조사 사양서·공식 페이지에서 확인
- **판매처 자료**: 판매처·유통사 자료로만 확인 → 현장 사용 전 공식 사양서 확인 권장
- **사용자 입력**: 직접 추가한 장비

공식/판매처 자료로 확인되지 않은 모델은 넣지 않았습니다.
수신카드 용량은 모듈 IC(PWM/일반)와 스캔 방식에 따라 달라지므로 참고값입니다.

> 본 계산은 참고용입니다. 장비 사양은 제조사 사양서, 전기 공사는 전기 관련 법규와 자격자 확인을 따르십시오.

## 폴더 구조

```
src/
├─ types.ts              공통 타입
├─ data/                 제품 사양 (novastar, colorlight, cabinets)
├─ core/                 계산 (화면과 분리, 테스트 포함)
│  ├─ wiringCheck.ts     수동 배선 공통 검사 (중복·미연결·이웃 여부)
│  ├─ screenLayout.ts    해상도·크기
│  ├─ portCapacity.ts    포트 용량
│  ├─ dataMapping.ts     포트별 용량·포트 번호·컨트롤러 검사
│  ├─ receivingCard.ts   수신카드 수량
│  ├─ powerCalc.ts       전력·전류, 차단기 추천
│  ├─ powerCircuit.ts    회로별 전류 검사
│  ├─ threePhase.ts      상별 부하, 불평형률
│  ├─ report.ts          보고서 표 데이터
│  └─ analyze.ts         전체 계산 진입점
├─ store/                상태 관리, 실행 취소, 자동 저장, 배선 편집 함수
├─ export/               PNG, PDF, JSON
├─ components/
│  ├─ layout/            상단바, 설정 패널, 작업 영역, 결과 패널
│  ├─ diagram/           배선도 공용 (격자, 경로선, 범례, 확대/이동)
│  ├─ wiring/            수동 배선 편집 (도구 막대, 마우스 동작)
│  ├─ screen/ mapping/ power/ devices/ report/
│  └─ ui/                입력 필드, 버튼, 대화상자
└─ styles/               디자인 토큰, 레이아웃
```
